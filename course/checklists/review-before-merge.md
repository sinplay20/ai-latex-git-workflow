# Review Before Merge

- [ ] The receiving branch is identified.
- [ ] The Agent branch is compared against the receiving branch.
- [ ] All changed files have been reviewed.
- [ ] Tests or LaTeX builds pass.
- [ ] No unresolved conflict markers remain.
- [ ] The receiving branch working tree is clean.
- [ ] The learner has explicitly approved the merge.
- [ ] The source branch will be deleted only after successful verification.
