## Teaching value

The history intentionally contains:

- ordinary line edits;
- additions and deletions;
- file creation;
- directory splitting;
- file and directory renaming;
- stable paths modified across several commits;
- wrapper introduction;
- a final source tree that can be compiled in two modes.

The dramatic text is presented as a short teaching excerpt with lightly normalized punctuation. Editorial context, notes, manifests, and build structure are original course materials.
