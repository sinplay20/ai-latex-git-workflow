# Review Before Merge

- [ ] Correct task branch and receiving branch identified.
- [ ] Every changed, added, deleted, and renamed file reviewed.
- [ ] No unrelated line rewrapping or formatting noise.
- [ ] Theorem hypotheses and conclusions checked.
- [ ] Proof dependencies and cross-references checked.
- [ ] Citation keys and bibliography checked.
- [ ] Working build succeeds.
- [ ] Submission build succeeds where relevant.
- [ ] PDFs visually inspected.
- [ ] Human author explicitly approves the merge.
