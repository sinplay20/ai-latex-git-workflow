# Before an Agent Edits

- [ ] The correct repository folder is open.
- [ ] The repository root has been verified.
- [ ] The current branch is known.
- [ ] `Changes` is empty, or existing changes have been reviewed and saved.
- [ ] A reliable checkpoint Commit exists.
- [ ] A task branch has been created for nontrivial work.
- [ ] The Agent has been told exactly which files and sections it may modify.
- [ ] The Agent has been told not to create `v2`, `new`, or `final-final` copies.
- [ ] The Agent has been told not to run Git mutations without approval.
- [ ] The expected compilation command is known.
