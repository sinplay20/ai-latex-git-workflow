# Roadmap

## Current release: documentation-first

- Chinese interactive course;
- Agent instructor protocol;
- nine-version Hamlet Git example;
- portable Git bundle;
- modular single-paper template;
- VS Code and PowerShell workflows;
- no Agent Skill and no automatic Commit daemon.

## Near term

1. Add a local bare-remote exercise to Lesson 10.
2. Add two-clone collaboration fixtures for Lesson 11.
3. Add a deterministic conflict generator for Lesson 12.
4. Add `latexdiff` examples.
5. Add screenshot-based VS Code guides.
6. Test the course with learners using different VS Code versions.
7. Add macOS/Linux command variants.

## Future automation

1. Agent Skill that loads only the current lesson.
2. Read-only repository diagnostic tool.
3. Confirmation-gated Git tool or MCP server.
4. VS Code command palette integration.
5. Optional progress tracking with explicit learner consent.
6. CI validation of bundles, history shape, links, and LaTeX builds.
7. Worktree orchestration for isolated parallel Agents.

## Design constraint

Automation must preserve human authority over mathematical claims, editorial decisions, Commit, Merge, Revert, publication, and knowledge-system writes.
