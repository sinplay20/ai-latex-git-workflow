# Course Materials

Start with [`COURSE.md`](COURSE.md). An Agent instructor must also read
[`instructor/AGENT-INSTRUCTOR-PROTOCOL.md`](instructor/AGENT-INSTRUCTOR-PROTOCOL.md).

The numbered lessons are under `lessons/`. Course state is not automatically
saved; use `templates/student-progress-template.md` only with learner approval.

Current delivery is documentation- and prompt-based. There is intentionally no
`SKILL.md` in this release.
