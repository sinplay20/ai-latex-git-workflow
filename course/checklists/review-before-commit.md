# Review Before Commit

- [ ] Every changed, added, deleted, and renamed file is understood.
- [ ] The Diff contains no unrelated reformatting.
- [ ] The mathematical statements and hypotheses are correct.
- [ ] Labels, references, citations, and bibliography keys remain valid.
- [ ] No private or temporary file was added.
- [ ] The intended LaTeX build succeeds.
- [ ] The PDF was visually inspected where relevant.
- [ ] Only intended files or hunks are staged.
- [ ] The Commit message describes one coherent change.
