# Manuscript Agent Rules

## Scope

- Read the relevant source before editing.
- Modify only files explicitly named in the task.
- Do not create `v2`, `new`, `final`, or date-stamped manuscript copies unless requested.
- Do not delete or rename manuscript files without explicit approval.

## LaTeX integrity

- Preserve labels, references, citations, theorem environments, and semantic line breaks.
- Avoid rewrapping unrelated prose.
- Keep generated files under `build/`.

## Git

- Do not run Git mutation commands unless explicitly asked.
- Do not Commit, Merge, Revert, Reset, Clean, Push, or create tags autonomously.

## Completion report

Report:

1. changed files;
2. mathematical changes;
3. editorial changes;
4. compilation result;
5. warnings or unresolved questions.
